# Picogon
The Picogon in an opensource RP2354A based board for compact embedded applications. Designed as a host platform to integrate with more complex use cases, with peripherals attachable via exposed ENIG pads that connect to spring contacts on a compatible daughterboard. 

## Features:

- USB-C PD/PPS (3.3V to 24V)
- Battery management (3.7V LiPo)
- WiFi/BLE (2.4GHz built-in antenna)
- LoRa (SX1262 868-915MHz UFL connector)
- 9-axis DoF (IMU + Magnetometer)
- QWIIC/Stemma I2C port
